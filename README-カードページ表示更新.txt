カードページの表示改善 更新ファイル

今回の更新：
・カード画像をカードページ上部中央へ配置。画像サイズとタップ拡大は維持
・カード名コピーを一旦削除
・概要をQ&Aと同じ全幅に変更。短い概要は常時表示し、長い概要は見出し・箇条書き単位で開閉
・関連カード欄に、関連先カードが掲載している該当裁定を追加。カード名はリンク、Q&Aと概要内の裁定は開閉式
・各カードの末尾に「このカードについて問い合わせる」を追加。問い合わせ先設定までは準備中表示
・Q&A表示時に、カード名内の空白は保持しながら、文中の明らかな余分な空白を整理
・PWAキャッシュを更新

適用方法：
ZIPを展開し、app.js、styles.css、sw.jsをGitHub Desktopで管理しているサイトのフォルダー直下へ上書きコピーします。その後GitHub DesktopでコミットしてPush originしてください。公開後にPWAで古い表示が残る場合は再読み込みしてください。
