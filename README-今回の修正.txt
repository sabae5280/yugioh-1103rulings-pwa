【適用方法】
1. ZIPを展開します。
2. 展開したファイルと images フォルダーを、GitHub Desktopで管理しているサイトのフォルダー直下へコピーし、同名ファイルは上書きします。
3. GitHub Desktopで変更を確認してコミットし、Push originします。
4. 公開後、PWAで古い表示が残る場合は一度再読み込みしてください。

ZIP内にはサイト全体ではなく、更新対象のファイルのみを収録しています。
