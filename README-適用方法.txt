10月9日② 更新用差分パッケージ

【適用】
既存の最新サイトに、このZIPの中身をフォルダー構造を維持して上書きしてください。
サイト全体の完全版ではありません。既存のカード・画像は削除しないでください。
10月7日と10月9日①の更新ファイルも同梱しています。
公開サイトへのアップロードは行っていません。

【今回の変更】
・カードリンクで検索結果の先頭を開いていた処理を廃止し、カード名の一致で指定。
・表示環境を維持して対象外カードを一時表示。対象外である旨を画面に表示。
・元のカード、開いていたQ&A・概要、検索語、スクロール位置を復元。
・未掲載カードは未掲載と表示し、別カードを開かない。
・スマホのヘッダーと検索エリアを縮小。長い説明はメニュー内へ移動。
・環境選択は初回に画像ボタンを表示。選択後は「現在：○○環境 変更」に縮小。
・画像の下に環境名と選択チェックを表示。
・内容検索時に該当Q&Aの文章を表示し、ボタンでそのQ&Aを直接開く。
・添付１００９②.docxから、カード46件と召喚権について1項目を追加・統合。
・Q&A142件、画像46枚を収録。
・コピー・プラントの原稿で回答空欄の1件は「回答準備中」と表示。
・原稿中の「要確認」など閲覧者向け注意書きは維持。
・PWAキャッシュをv57に更新。

【確認状況】
構文、カード・Q&A・画像の対応、リンク先の厳密指定、環境維持、連続参照からの復帰、
開閉状態とスクロール位置の復元、Q&Aへの直接移動、環境ボタンの保存・折りたたみをコードで検証済み。
実ブラウザーでの表示確認は未完了です。ブラウザー操作の自動承認審査が利用上限で停止しているためです。
手元の確認用サイト一式には以前の一部ファイルが欠けており、全体のオフライン動作は未確認です。
