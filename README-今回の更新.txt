遊戯王裁定サイト 更新ファイル

今回の主な変更
・カード画像と拡大案内から概要までの余分な間隔を縮小
・概要を従来の黄色い枠で一括表示。自動で概要全体を折りたたまず、明示された箇所のみ開閉
・概要内の「【タップで開く】見出し」で、その見出し以下を次の「－区切り線－」または次の開閉見出しまで折りたたみ
・概要内の「－区切り線－」を区切り線として表示
・関連カード・裁定内のカード名リンクを青字にし、薄青の円形背景を削除
・添付資料のカードと裁定データ34項目、Q&A87件、カード画像34点を追加・統合
・#1209／#1402タグを各データに適用。タグのない「オーバースペック」は全環境で表示
・既存カードの概要・Q&A指定修正を適用
・PWAキャッシュを更新

今後の概要の指定方法
開閉させたい見出しの行を「【タップで開く】見出し」の形にし、その後に折りたたむ本文を続けます。
「－区切り線－」を置くと開閉本文がそこで終わり、区切り線が表示されます。
この印がない概要は黄色い枠の中に最初から表示されます。

適用方法
1. ZIPを展開します。
2. ZIP内のファイルと images/additional-20261004 フォルダーを、GitHub Desktopで管理しているサイトのフォルダー直下へコピーし、同名ファイルを上書きします。
3. GitHub Desktopで変更を確認してコミットし、Push originします。
4. 公開後、PWAで古い表示が残る場合は再読み込みしてください。

ZIPにはサイト全体ではなく、更新対象ファイルと新規データ・画像のみを収録しています。
