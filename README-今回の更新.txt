変更内容

・すべてのカード概要の先頭に、常時表示される【基本情報】を配置。

・概要の見出しはアイコンを維持して色を変え、本文より少し大きく表示。見出しと本文を別の行に分け、直下に余白を設定。
・概要の▶を■として表示し、■と▷の項目を空行なしの余白で区切る。マーカーと本文の開始位置を揃える。
・概要内の「－区切り線－」など区切り線のみの行を表示しない。
・カード概要の文章だけを、意味を保ったまま「だ・である」調に整える。Q&A本文は変更しない。
・関連裁定内のカード名リンクを、青字の太字に変更。青い丸囲みは維持。
・PWAのキャッシュバージョンをv52へ更新。
