概要の表示方法
開閉させたい見出しの行を「【タップで開く】見出し」の形にし、その後に折りたたむ本文を続けます。「－区切り線－」を置くと開閉本文がそこで終わり、区切り線が表示されます。この印がない概要は黄色い枠の中に最初から表示されます。

適用方法
1. ZIPを展開します。
2. ZIP内のファイルと images/additional-20261004 フォルダーを、GitHub Desktopで管理しているサイトのフォルダー直下へコピーし、同名ファイルを上書きします。
3. GitHub Desktopで変更を確認してコミットし、Push originします。
4. 公開後、PWAで古い表示が残る場合は再読み込みしてください。

このZIPにはサイト全体ではなく、更新対象ファイルと新規データ・画像を収録しています。
