管理ID 表示・コピー・検索 更新ファイル

このZIPを展開し、READMEを除く13ファイルをGitHubリポジトリのルートへ配置してください。同名ファイルは上書きします。管理ID付与ツールの assign-management-ids.cjs もルートに置いてください。

既存の裁定データ9ファイルにあるQ&Aへ、重複しないランダム英数字IDを保存しています。各IDは裁定データ内に保持されるため、裁定の並べ替えや質問・回答の文章修正後も変わりません。共有裁定はカードごとに異なるIDです。

各Q&A枠の右下にIDを表示します。コピー操作では「ID：R-XXXXXXXXXX」の形式でコピーされます。検索欄ではIDの全部または一部で検索できます。

今後、新しい裁定データを追加してindex.htmlから読み込むようにした後、GitHubリポジトリのルートで `node assign-management-ids.cjs` を実行すると、未付与IDを保存し、全裁定の欠落・重複を検査します。検査に失敗した場合はファイルを書き換えません。

は行の裁定データはこのZIPに含まれていません。原稿を受領後、は行データと管理IDを追加した更新ZIPを作成します。
