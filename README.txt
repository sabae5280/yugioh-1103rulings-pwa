ま行・や行カード追加（2026年10月22日）

配置方法
ZIPを展開し、以下をすべてGitHubリポジトリのルートへ配置してください。
・rulings-maya-20261022.js（追加）
・index.html（同名ファイルを置き換え）
・sw.js（同名ファイルを置き換え）
・maya-20261022-card-01.png ～ maya-20261022-card-18.png（画像18枚を追加）
新しいフォルダーを作る必要はありません。画像もJavaScriptと同じ階層に置きます。
README.txtはアップロード不要です。反映後、サイトを再読み込みしてください。

基準と内容
origin/main 2a2d5d4（よんふさんハ行追加）を取得して作成。
新規18枚・Q&A54件・画像18枚を追加します。
既存データとすべての上書きファイルの読み込み後に追加されます。
同名カードが既に存在する場合は上書きせず、二重読み込みでも重複登録しません。

環境指定
・カードの1209／1402タグを適用。個別質問の環境タグがあればそちらを優先。
・今回、個別質問内の環境タグはありませんでした。
・指定なしの明鏡止水の心は1103環境。
・魔導教士 システィに「エンドフェイズの処理」タグを設定。

表記
・Q&A管理IDはR-ランダム英数字8桁。
・Q&A内の当該カード自身の名称を「このカード」に整理。
・概要の見出し記号を■に統一。
・ダメージステップの効果／適用処理にDS表の対応表記を設定。
・ハイロンの質問の誤記「効果は対象を発動し」を「効果を発動し」に整理。
・Q&A欄が空欄の4枚（バテル、アバコーンウェイ、アンフィスバエナ、ユニコーン）
  は、画像・概要・ルビ等のみ追加。
・ハバキリとヘツカの修正は含めていません。
