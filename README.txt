・[DS表①ダメージステップ開始時]～[DS表⑥ダメージステップ終了時]と、
  [DS表③ダメージ計算時]への言及を追加。

・ダメージ計算後、発動した効果による攻撃力変更は復活しないと整理。
・デーモンの斧等の永続的な攻撃力変更は、ダメージ計算後に再計算すると整理。
両カードともQ&Aと管理IDは変更していません。

元資料内の確認事項
RUM－七皇の剣は、概要に「効果の発動や効果が無効になった場合でも再使用できない」
という説明がある一方、Q&Aには「カードの発動が無効になった場合、2枚目の発動と
効果適用が可能」という回答があります。提供された表現を維持しています。
今後概要を整理する際は、カードの発動と効果の発動の区別も含めて確認してください。
