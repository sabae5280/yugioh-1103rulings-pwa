管理ID 表示・コピー・検索 更新ファイル

このZIPを展開し、READMEを除く12ファイルをGitHubリポジトリのルートにある同名ファイルへ上書きしてください。

Q&A裁定データ9ファイルすべてに、ランダムな英数字の管理IDを保存しました。IDは裁定データの各項目に記録されるため、表示順や質問・回答の文章を編集しても変わりません。共有裁定もカードごとに異なるIDになります。

サイトでは各Q&A枠の右下にIDを表示します。コピーを押すと「【ID：管理ID～】」の形式でコピーされ、検索欄ではIDの全部または一部で検索できます。

注意：は行のデータは、作業フォルダにまだ届いていないため、この更新には含まれていません。は行データを追加する際は、同じ形式でIDを付けてください。
